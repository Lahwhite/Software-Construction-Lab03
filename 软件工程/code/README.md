## 根据 UML 图实现代码

### 你是如何将UML图转换为代码的，最后实现的软件源代码规模是多少

将 UML 的类图以及需求分类一并提交给大模型，在大模型解析之后自行完成代码。

最后实现的软件源代码大概在一千五百行左右，其中包含了九百行 UI 设计代码。

#### 你让大模型帮助你做了哪些工作

框架搭建以及代码填充。

#### 如果大模型生成的内容不符合你的预期，你是怎么做的

选中强相关内容，描述与预期的不符情况，明确我需要的目标，再次生成相关内容。
